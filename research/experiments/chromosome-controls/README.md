# إعادة فحص مقارنة الصبغيات

هذه تجربة وصفية داخل نص القرآن المثبت، وليست تقديرا لاحتمال القصد أو المصادفة العامة. ثبت البروتوكول في commit `eacece6f9cc3a0f5782457db542e0e6336477eea` قبل تشغيل المقارنة. النتيجة الرئيسة: تحقق شرط انقسام المجموعين على 46 تحت C3 في 10 من 10000 سحب. حدود التصميم في [البروتوكول](protocol.md) و[مذكرة النتائج](../../notes/chromosome-controls-audit.md).

من جذر المستودع، بالبيئة المثبتة CPython 3.14.4 وUnicode 16.0.0:

```bash
python3 research/experiments/chromosome-controls/audit_independent.py
python3 -m unittest discover -s research/experiments/chromosome-controls -p 'test_*.py' -v
```

الأمر الأول يقرأ المصدرين والملفات المحفوظة ويعيد بناء جميع الأحواض والسحوبات والمجاميع دون تعديلها. لا يستورد برنامج التجربة أو مكتبة النص في المشروع. الاختبارات الثمانية للتنفيذ والأربعة للتدقيق تشمل البسملة والتداخل والطبقات والبذرة والتلاعب بالمخرجات في نسخ مؤقتة.

`draws.jsonl` يحفظ كل السحوبات، و`pools.json` يحفظ جميع البدائل بالترتيب، و`summary.json` يعرض النتائج، و`run-manifest.json` يربط البروتوكول والمصدر والبرنامج والمخرجات ببصماتها. يثبت [التدقيق المستقل](../../reviews/2026-11-02-controls-independent-result.json) إعادة الحساب. لا يشحن ملف السحوبات الكبير مع صفحة المقال؛ يحتفظ به المستودع، ويتيح الموقع الملخص والبروتوكول عند الطلب.

برنامج `run.py` هو مولد التجربة الأصلي؛ إعادة تشغيله تعيد كتابة ملفات النتائج وإيصال التشغيل الزمني. للفحص المعتاد يكفي برنامج التدقيق أعلاه، الذي يحافظ على سجل التشغيل الأول. يجب إبقاء البروتوكول المجمد حرفيا؛ أي تصميم آخر يحتاج ملفا وقرارا جديدين قبل حسابه.
