للتدقيق الكتابي فقط: ضم المقاطع وحذف المسافات يعطي78 رمزًا حرفيًا في Simple Clean، منها14 حرفًا مختلفًا: ا، ح، ر، س، ص، ط، ع، ق، ك، ل، م، ن، ه، ي. هذه ليست أطوال أسماء الحروف عند التلاوة، ولا وزنًا صوتيًا، ولا دليل رسالة مشفرة. لا توسع قيمة العدد إلى رسم آخر دون سياسة جديدة معلنة.

```python
from quran_research.corpus import load_corpus, BASMALAS
forms = {'الم','المص','الر','المر','كهيعص','طه','طسم','طس','يس','ص','حم','ق','ن'}
verses = load_corpus('.')
lookup = {(v.surah, v.ayah): v for v in verses}
rows = []
for v in verses:
    if v.ayah != 1:
        continue
    words = v.text.split()
    offset = 4 if v.surah != 1 and tuple(words[:4]) in BASMALAS else 0
    if words[offset] not in forms:
        continue
    parts = [(v.ref, offset + 1, words[offset])]
    if v.surah == 42:
        assert lookup[42, 2].text == 'عسق'
        parts.append(('42:2', 1, 'عسق'))
    rows.append(parts)
assert len(rows) == 29
assert sum(map(len, rows)) == 30
patterns = [' '.join(p[2] for p in row) for row in rows]
assert len(set(patterns)) == 14
letters = ''.join(patterns).replace(' ', '')
assert (len(letters), len(set(letters))) == (78, 14)
for row in rows:
    print(row)
```
