# WhyQaraan — لماذا هذا اللفظ هنا؟

مختبر بحث عربي في استعمال ألفاظ القرآن، واختلاف التعبير بين الآيات، والنظم والبلاغة، والأسماء والأعداد، وصلات محتملة بالعلم والوراثة، وبناء أحكام الأسرة. الغاية مقالات عربية موثقة ومقروءة، ثم موقع ثابت قليل الموارد.

نبدأ بنتائج منشورة قابلة للتوثيق وإعادة الفحص، ونستخدمها لاقتراح أسئلة جديدة. لا نفترض أن كل ادعاء مشهور ثابت، ولا نسمي نتيجة جديدة قبل البحث عن سوابقها. تظل الملاحظة النصية والتفسير والفرضية العلمية أنواعًا مختلفة من المعرفة.

## ما الموجود الآن؟

- القرآن كاملا بنسختين من [مشروع تنزيل](https://tanzil.net)، وبيانات 114 سورة و6236 آية وفق هذا الترقيم، مع الرخصة والبصمات.
- عد دقيق للصيغ والعبارات المحددة، وفهرس لكل صيغة مكتوبة ومواقعها، وسياق محيط بكل مطابقة.
- سجلات قراءة كاملة مستقلة للباحثين، ودراسات بمصادرها وحدودها وأسئلتها التالية.
- [منهج البحث](docs/methodology.md)، و[اختيار تقنية الموقع](docs/website.md)، و[سجل الفرضيات](research/hypotheses.json)، و[تقدم العمل](research/PROGRESS.md).

## التشغيل

يلزم Python 3.11 أو أحدث. لا تثبيت لحزم خارجية، ولا حساب سحابي، ولا قاعدة بيانات. اختبر التوافق على Python 3.14.4 في هذه المرحلة.

```bash
cd /home/amari/Projects/WhyQaraan
python3 -m unittest discover -s tests -v
python3 -m quran_research verify
python3 -m quran_research count 'فبأي آلاء ربكما تكذبان' --surah 55
python3 -m quran_research concordance تسطع تستطع --radius 2
python3 -m quran_research compare سنة سنين عام عاما
python3 -m quran_research inventory
python3 -m quran_research characters
python3 -m quran_research characters --corpus uthmani
python3 -m quran_research universe
python3 -m quran_research build
```

`reports/catalog.json` يجمع الأدلة والقراءات ونتائج الاستعلامات وسياقاتها. `reports/word-index.json` يفهرس جميع الصيغ المكتوبة، وهو مادة بحثية لا يلزم إرسالها كاملة إلى متصفح كل قارئ.

`reports/repetition-summary.json` يعرض أكثر الصيغ تكرارا وعدد الصيغ المتكررة والفريدة، و`reports/characters-*.json` يحفظ توزيع الرموز لكل نسخة. `reports/universe.json` يعرض مجموعات ألفاظ الكون وكل صيغها ومواضعها وتحفظاتها الدلالية، وفق القوائم المراجعة في `research/universe-terms.json`.

## كيف نفهم العد؟

الافتراضي هو `Simple Clean`: النص الذي يقدمه تنزيل بلا تشكيل؛ لا نزيل أو نوحد حروفًا إضافية. «يوم» و«اليوم» و«يوما» صيغ مختلفة. يجوز جمع قائمة صريحة منها مع عرض القائمة، ولا تسمى هذه العملية بحثًا عن الجذر. العبارات تطابق داخل الآية ولا تمتد إلى الآية التالية. تكرار العبارة داخل الآية يحتسب أكثر من مرة. عند جمع عبارات متداخلة يحتسب كل نمط مستقل؛ راجع تعريف التجربة.

ملفات المصدر تضيف بسملة إلى أول آية في 112 سورة غير الفاتحة والتوبة. يستثنيها العد الافتراضي دون تغيير النص المحفوظ، ويبقي بسملة 1:1 والبسملة داخل 27:30. للمقارنة مع كامل محتوى الملف استخدم `--include-opening-basmalas`. تظل مواقع الكلمات مرقمة من 1 في السطر الأصلي بما فيه البسملة.

للمطابقة الحرفية في الرسم العثماني استخدم `--corpus uthmani` مع صيغة مشكلة مطابقة. لا تفسر غياب نتيجة بسبب اختلاف الرسم على أنه غياب اللفظ. لا يوجد حاليا محلل صرفي أو قاعدة أسماء شاملة؛ هذه تتطلب تعريفات ومراجعة مستقلة.

أمر `characters` يعد نقاط Unicode غير البيضاء في متن الآيات، ويعرض كل رمز وتكراره وتصنيفه، مع فصل الحروف والعلامات والتطويل. لا يدمج «ا/أ/إ/آ» ولا يزيل الهمزة المركبة. لذلك فهو عد حرفي لترميز الملف، وليس إحصاء تراثيًا متفقًا عليه لحروف الرسم أو الأصوات. تختلف النتائج باختلاف الرسم والتشكيل وسياسة البسملة؛ كل تقرير يسجلها صراحة.

## القراءة والمراجعة

لكل وكيل بحثي سجل في `research/readings/`. التحقق يرفض فجوة أو تكرارًا أو اختلاف البصمة، ويرفض اعتماد دراسة بلا قارئ أكمل النص. هذه السجلات إقرارات موثقة بالتغطية، ولا تضمن الفهم أو بقاء النص كله في نافذة سياق واحدة. خضع بعض الباحثين لضغط سياق وأوضحوا ذلك في سجلهم. ليس العبور البرمجي للنص قراءة.

## المقالات والموقع

المقالات في `content/articles/` مسودات عربية ذات مصادر. اختيار المرحلة المقبلة هو Astro بتوليد ثابت ومجموعات محتوى Markdown؛ ملفات HTML وCSS وصور وJSON عند الحاجة، بلا خادم تطبيق دائم. لم يُنشأ موقع منشور في هذه المرحلة.
