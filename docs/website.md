# موقع WhyQaraan بأقل موارد تشغيل

## القرار

Astro بتوليد صفحات ثابتة، ومقالات عربية في Markdown ومجموعات محتوى تتحقق من حقول المقالات وقت البناء. تؤكد [وثائق Astro](https://docs.astro.build/en/guides/on-demand-rendering/) أن الإعداد الافتراضي يولد الصفحات وقت البناء. وتناسب [مجموعات المحتوى وقت البناء](https://docs.astro.build/en/guides/content-collections/) المقالات والبيانات التي تتغير عند التحرير.

تعمل أدوات Python محليا أو في مهمة البناء. تنتج JSON ثابتًا ونتائج يمكن الرجوع إليها. يستقبل القارئ HTML وCSS والصور اللازمة؛ لا نحتاج جلسات مستخدمين أو اتصالًا بقاعدة بيانات لقراءة المقالات. لا نحمل فهرس القرآن الكامل لكل زيارة؛ يمكن تقسيم فهارس البحث عند الحاجة.

## المكونات المنفذة محليا

- لغة `ar` واتجاه `rtl`، وخط عربي واضح، وصفحات مريحة للقراءة على الهاتف.
- فهرس مقالات حسب الألفاظ والأسماء والبلاغة والأعداد والعلوم والأسرة، وصفحة لكل مقال.
- في المقال: السؤال، النص والسياق، التحليل، النتيجة وحدودها، المصادر، وطريقة إعادة الحساب إن وجدت.
- رابط بيانات الدليل وتاريخ المراجعة، مع توضيح هل المحتوى ملاحظة أو تفسير أو فرضية.
- نشر المقالات التي خرجت من حالة المسودة فقط. لا تصدير واجهة ترخص في تغيير النص المصدر.
- بحث في المتصفح عند الحاجة إلى ذلك، مع تحميل كسول للفهارس؛ لا حاجة إليه في أول صفحة مقالات.
- استضافة ملفات ثابتة على CDN أو خادم ملفات عادي. اختيار مزود ودومين ونشر فعلي في مرحلة لاحقة.

نفذت الصفحة الرئيسية، وفهرس المقالات، وصفحات 13 مقالة، وصفحة العد والتنزيلات، والمنهج، وخريطة البحث ذات 41 موضوعا، وصفحة 404. توجد 19 صفحة HTML في هذا البناء. السجل المنظم في research/website-backlog.json؛ يتولد منه أيضا سجل Markdown المقروء بأمر python3 tools/render_backlog.py.

يسبق اعتماد المقال مراجعة بحثية داخلية مستقلة، تحفظ في JSON مع بصمة المتن والمراجع والتاريخ. يفشل البناء إذا تغير المتن دون مراجعة أو كانت إحالة الأدلة أو المراجعة غير صحيحة. لا يصل مقال draft:true إلى مسار في بناء الإنتاج. وضع SHOW_DRAFTS=true للمراجعة المحلية فقط ويضيف تنبيها ظاهرا وnoindex.

## قياسات البناء المحلي

في بناء 2026-11-02 بعد الجولة البحثية الثالثة: صفر بايت JavaScript للمتصفح، و11057 بايت CSS، والصفحة الرئيسية 7067 بايت HTML، ومقال العد 10613 بايت HTML، ومقال اليوم والشهر 14865 بايت. أكبر صفحة هي خريطة البحث: 53370 بايت. هذه أحجام ملفات قبل ضغط النقل، وليست قياس زمن وصول من استضافة عامة.

إجمالي مجلد dist يبلغ 1839517 بايت، نحو 1.84 ميغابايت، ويشمل تنزيلات JSON؛ لا يحملها المتصفح إلا عند طلبها. لا قاعدة بيانات ولا خادم تطبيق دائم ولا خطوط خارجية. كلفة البناء والتخزين ونقل البيانات تبقى مرتبطة بالاستضافة المختارة لاحقا.

## صيغة المقال

الملفات في `content/articles/` تستخدم frontmatter يحوي `title`, `description`, `date`, `draft`, `evidence_ids`, `category`. يضاف للمعتمد `reviewed_by`, `reviewed_at`, `review_record`. يبقى المتن عربيا، وتصل أسماء الأدلة المقال بسجل قابل للفحص. لا MDX أو React أو محرر في المتصفح.

## التشغيل والتحقق

راجع README لأوامر npm وPython. ينتج npm run build ملفات dist، وnpm run build:preview ملفات dist-preview. يتحقق npm run check من TypeScript وبوابات المقالات والسجل. يجرب npm run test:publication-builds بناء نسخة مؤقتة بها مسودة اصطناعية؛ لا يغير شجرة المقالات الأصلية. يجب أن تبقى فحوص المصدر وسجلات القراءة والعد جزءا من مسار البناء، ولا يكفي نجاح قوالب HTML وحده.

تتحقق ملفات التعليقات الآن من اكتمال كل قائمة ومواقع الكلمات وتطابق مجالها مع الاستعلام المركزي وإشعار المصدر وأهلية القارئ. لا يثبت هذا صحة التصنيف الدلالي؛ لذلك تحفظ المراجعة المستقلة أيضا. اختبر البناء الفعلي رفض وقوع محذوف ورفض سجل قراءة مزور، مع حجب المسودات وعدم تلويث مخابئ النسخة الأصلية. اجتازت الجولة 32 اختبار Python و32 اختبار موقع، وفحص متصفح لعشر حالات مسار/عرض، مع 358 رابطا محليا سليما. التفاصيل في research/reviews/2026-11-02-research-batch-verification.json.
