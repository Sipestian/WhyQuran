# خطة الجولة البحثية الثانية بعد النشر

**الهدف:** متابعة الأسئلة المحفوظة في الإصدار الأول بثلاث دراسات عربية قابلة للمراجعة والنشر.

**التفويض:** طلب المستخدم «resume» بعد نشر الإصدار الأول، مع تفويضه السابق بالعمل المستقل وحفظ ما يستحق الموقع. نحافظ على الموقع العام نفسه وعلى Astro الثابت وغياب JavaScript للمتصفح. العمل في المستودع والفرع القائمين `website-research`؛ لا حاجة إلى تغيير المنصة أو إنشاء مشروع آخر.

**الاختيار:** تعميق ثلاث دراسات قائمة يربط البحث الجديد بأساس موثق. إضافة موضوعات متفرقة تؤجل الأسئلة المفتوحة؛ وتوسيع الادعاءات العددية قبل تحديد قواعدها لا يعطي اختبارا منضبطا. هذا اختيار المنسق ضمن التفويض، وليس اختيارا جديدا منسوبا إلى المستخدم.

- اكتمال الـ31 وقوعا لا يضمن صحة تصنيف الوظيفة البلاغية؛ تراجع الحالات الحدودية وتبقى قابلة للاختلاف.

- مقارنة آيات منتقاة بطولها تحافظ على خواص محددة فقط، ولا تمثل نموذج لغة أو قصد أو إعجاز.

- المقالات تبقى مسودات حتى المراجعة، والواجهة والبيانات لا توحيان بأن المراجعة الآلية تحكيم بشري.
