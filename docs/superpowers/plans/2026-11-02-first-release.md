# WhyQaraan First Release Implementation Plan

> **For agentic workers:** Use the established subagent-driven-development workflow with the three existing full-Quran readers. Do not create research agents without the required reading coverage.

**Goal:** إكمال تغطية موضوعات السجل بمقالات وتقييمات عربية مراجعة، والتحقق من الموقع ونشر الإصدار الثابت.

**Architecture:** تبقى المقالات Markdown والأدلة JSON وأدوات العد Python، مع تحقق عند بناء Astro. يربط release-plan الموضوع بالمقال وصاحب العمل، وتتحكم بصمة المراجعة في ظهوره.

**Tech Stack:** Astro7.4.4، Node>=24، Python>=3.11، Sites للاستضافة الثابتة.

**Spec:** `docs/superpowers/specs/2026-11-02-first-release-design.md`

## Global Constraints

العربية وRTL؛ لا تغيير للنص المثبت؛ لا ادعاء جدة أو سبق علمي دون حجة؛ لا نشر مسودة؛ لا بيانات اعتماد في الملفات؛ لا قاعدة بيانات أو JavaScript للمتصفح. تسبق مراجعة مستقلة اعتماد كل متن. تحفظ نقاط التوقف قبل انتظار مادة خارجية مطولا.

## Review Focus

- ادعاء العد الذي يتبدل بالرسم أو البسملة أو اشتراك كلمات في آية: يذكر القاعدة وكل المواضع ولا يضبطها بعد النتيجة.
- التشابه بين لفظ قديم ومصطلح حديث: يفصل التفسير والدليل التجريبي والتاريخ ولا يطلق «إثبات» على مجرد توافق.
- الحكم الأسري أو الوصف البيولوجي ذو الاستثناءات: يجمع المصادر ويظهر الخلاف والتباين ولا يصاغ قاعدة عامة مضللة.
- بطاقة مغطاة عنوانا فقط: يلزم مقال يعالج سؤالها فعلا ومراجع مستقلة، لا تغيير الحالة آليا لمجرد وجود رابط.
- النسخة المنشورة: تطابق المصدر المحفوظ، ولا تسرب المسودات أو بيانات الاعتماد، وتبقى روابطها وبياناتها سليمة.

## المهام

- [x] قراءة الحالة الحالية وتعليمات المستودع، وتثبيت مصفوفة تغطية الموضوعات، وإعادة تشغيل الباحثين المؤهلين.
- [x] الموجة الأولى: الصبغيات والتطور الجنسي؛ العدة والميثاق ومنهج الأحكام؛ الاستطاعة والقصص والحروف المقطعة. المخرجات المذكورة في release-plan: مذكرة، دليل، مقال مسودة؛ فحص مواضع ومصادر قبل المراجعة.
- [x] مواد المنسق: شرح الحروف والرسم، ومعايير الاكتشاف والتوافق العددي، وخط زمني للقرن الأخير. تعتمد على الأدلة القائمة والمصادر الأولية؛ يراجعها قارئ مستقل قبل الاعتماد.
- [x] الموجة الثانية: الجنين والماء الدافق؛ الأسماء والعدد19؛ الماء والحياة والبحرين وبيت العنكبوت. تثبت القواعد والدعوى والنطاق قبل القياس، وتحفظ المصادر غير المقروءة كقيد.
- [x] الموجة الثالثة: نشأة الكون والمدارات وحركة الجبال. تجمع المقاطع وسياقها والتفسيرات، ثم تقارن بالمعلومة العلمية دون فرض المطابقة.
- [x] تبادل المراجعات بين المؤلفين؛ معالجة الملاحظات الجوهرية؛ حفظ القرار وبصمة المتن في ملفات reviews؛ دمج الاستعلامات وبيانات التنزيل بعد اكتمالها فقط.
- [x] فحص مصفوفة الإصدار: كل topic_id موجود، وكل مقال معتمد، وروابط الأدلة صحيحة. تحديث السجل مع بقاء السؤال التالي الحقيقي وعدم محو النتائج السلبية.
- [x] تهيئة النشر: أصل الموقع وcanonical وخريطة XML وrobots؛ اختبار عدم إدراج المسودات وصحة العناوين المطلقة، دون إضافة JavaScript.
- [x] التحقق النهائي: اختبارات Python وnpm run check، ثم build واختبار البناء الفعلي عند تغير بواباته، ثم فحص الهاتف وسطح المكتب والروابط والبيانات.
- [x] حزم مصدر مطابق عبر Sites helper وحفظه ونشره؛ تحقق من نتيجة الأداة والجمهور والعنوان الفعلي. حفظ سجل الإصدار والتسليم دون سر أو ادعاء تحقق لم يحدث.

## ملكية الملفات

يتولى كل باحث الملفات الجديدة المسندة إليه فقط. يتولى root السجل المركزي والاستعلامات ومراجعات النشر والواجهة والاختبارات والنشر والدمج. يجوز للمراجع بعد تسلم الحزمة المكتملة تصحيح الخطأ مع توثيقه وتثبيت بصمة النسخة النهائية؛ لا يحرر المؤلف والمراجع الملف نفسه بالتوازي. لا تحتاج المقالات الجديدة اختبارات تحاكي محتواها؛ تتحقق الآليات ومصادر الأرقام والمواضع، وتراجع الدلالة قراءة مستقلة.
