# موقع WhyQaraan وسجل موضوعاته

## المقصد

موقع عربي للقراءة والبحث في ألفاظ القرآن وسياقاتها وأعدادها وصلاتها المقترحة بالعلم. طلب المالك مواصلة العمل باستقلال وحفظ كل ما يستحق الموقع. هذه المرحلة تنتج موقعا محليا قابلا للبناء الثابت وسجلا تحريريا دائما؛ اختيار الاستضافة والنطاق والنشر الفعلي لاحق.

## القرار والبدائل

نحافظ على اختيار Astro الموجود في docs/website.md. يولد HTML وCSS، بلا خادم تطبيق أو قاعدة بيانات عند القراءة. HTML اليدوي أبسط لأول صفحة لكنه يكرر قوالب المقالات، وNext.js أو نظام إدارة محتوى بخادم لا يخدم حاجة هذه المرحلة. اختيار Astro والتصميم التالي قرار تنفيذي ضمن تفويض المستخدم بالمضي، وليس ادعاء موافقة منفصلة على رسم واجهة.

## التجربة

- واجهة عربية RTL، خلفية ورقية فاتحة، حبر أخضر داكن، لون نحاسي محدود، تصميم تحريري مريح للهاتف والحاسوب. لا صور زخرفية ثقيلة ولا خطوط خارجية عند الزيارة.
- الرئيسية تعرض سؤال «لماذا هذا اللفظ هنا؟» ومدخلا مباشرا للمقالات والعد وخريطة البحث؛ المحتوى هو محور الصفحة.
- فهرس المقالات ومقال لكل Markdown، مع تصنيف وتاريخ وحالة مراجعة وروابط الأدلة والمصادر.
- صفحة العد تعرض النتائج من reports مع تعريف الوحدة والرسم والبسملة وتحفظات معجم الكون؛ لا تحميل word-index.json الضخم للمتصفح.
- صفحة المنهج توضح درجات الاستنتاج وحقوق المصدر؛ خريطة البحث تعرض موضوعات السجل التحريري وحالة كل منها والسؤال التالي.
- لا حاجة إلى JavaScript في القراءة والتنقل الأساسي. لا زر وهمي أو نموذج غير عامل أو وعد باكتشاف جديد.

## المحتوى والنشر

research/website-backlog.json هو السجل الرئيسي للموضوعات: id وtitle_ar وcategory وstatus وquestion_ar وbaseline_ar وverse_refs وevidence_ids وsource_urls وarticle_slug وnext_step_ar وqualification_ar. المذكرات المتخصصة تحفظ التفاصيل والمصادر.

لا تنشر مسودة في بناء الإنتاج. يمكن لمتغير SHOW_DRAFTS=true إظهارها للمراجعة المحلية، مع شارة ظاهرة وnoindex. الانتقال إلى draft:false يتطلب مراجعة مستقلة مسجلة في research/reviews/ وتوثيق reviewed_by وreviewed_at في المقال. العلمية المقبولة لا تعني اعتماد دعوى الإعجاز؛ تعرض الحدود قرب النتيجة.

## التحقق

الاحتفاظ باختبارات Python وفحص بصمات المصدر. تحقق من مراجع الأدلة وحقول المراجعة ومنع المسودات في البناء الافتراضي. افحص HTML الناتج للروابط المحلية واللغة والاتجاه وعدم تحميل JavaScript غير ضروري. افحص الواجهة في متصفح إن تيسر، على شاشة هاتف وحاسوب. لا تغير ملفات data/source.
