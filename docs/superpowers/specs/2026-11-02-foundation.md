# تأسيس WhyQaraan

المستخدم فوّض إنشاء المستودع والبحث بالعربية، واختيار التقنية، وإدارة عدة وكلاء بشرط قراءة كل وكيل بحثي القرآن كاملا. الاسم WhyQaraan، والموقع تحت مجلد المشاريع المحلي. هذه وثيقة قرارات التنفيذ ضمن التفويض، وليست موافقة مزعومة على تفاصيل لم يناقشها المستخدم.

## المقصد

تأسيس بحث قابل للتدقيق يبدأ بالألفاظ العربية واستعمالها، والاختلاف بين التعبيرات، والأسماء والأعداد. تُدرس الروابط بالعلم والوراثة، والزواج والطلاق وبناء الأحكام. النتائج المنشورة الموثقة هي نقطة البداية لفرضيات جديدة. لا يعد كل منشور حقيقة ثابتة.

## التنفيذ الأول

نص كامل من تنزيل، بنسختي Simple Clean وUthmani، محفوظ بلا تعديل مع بيانات السور والبصمات والرخصة. أدوات Python قياسية للتحقق، وفهارس الاستعمال، وعد الكلمات والعبارات دون مطابقة أجزاء الكلمات، وإظهار السياق، ومقارنة مجموعات ألفاظ صريحة. سجل أدلة JSON وسجل قراءة كامل لكل باحث. مقالات عربية أولية في Markdown، وبروتوكول للفرضيات والاستكشاف.

## قواعد العد

الافتراضي نص Simple Clean بلا أي تطبيع إضافي. حدود الكلمة هي المسافات. العد الافتراضي يستبعد البسملة التي يضيفها المصدر قبل أول آية للسور غير الفاتحة والتوبة، ويبقي البسملة المرقمة في الفاتحة وداخل 27:30. يوجد وضع يحتسب جميع كلمات ملف المصدر للمقارنة. لا يُستعمل هذا العد لادعاءات عدد الحروف في الرسم العثماني أو عدد الجذور.

## الموقع لاحقا

اخترت Astro بصفحات ثابتة ومجموعات محتوى Markdown. Python للبحث وقت البناء فقط، وJSON للتبادل؛ لا PHP أو خادم Node دائم أو قاعدة بيانات للقراءة. البدائل: مولد بسيط مخصص أقل اعتماديات لكنه يضيف صيانة القوالب؛ وتطبيق ديناميكي يضيف كلفة تشغيل لا تتطلبها المقالات. التأسيس الحالي يجهز البيانات والمقالات، ولا يساوي موقعا منشورا.

## حدود التسليم

اكتمال هذه المرحلة يعني مستودعا يعمل محليا، ونصا سليما، واختبارات ذات معنى، وسجلات دراسات ومصادر وقراءة، ومسودة طريق للمقالات. لا يعني حسم جميع أسئلة القرآن أو إثبات اكتشاف علمي جديد. القراءة الكاملة المسجلة لا تعني الاحتفاظ الحرفي بكل القرآن في سياق واحد.
